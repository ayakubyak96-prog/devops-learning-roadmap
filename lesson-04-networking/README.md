# Урок 04 — Сетевой стек Linux

## 1. Модели OSI и TCP/IP

### OSI (7 уровней)

| Уровень | Название | Задача | Примеры |
|:---|:---|:---|:---|
| 7 | Application | Приложение хочет отправить/получить данные | HTTP, SSH, DNS |
| 6 | Presentation | Формат данных, шифрование | TLS, JSON |
| 5 | Session | Управление сессиями | TCP-сессии, cookies |
| 4 | Transport | Доставка данных между процессами | TCP, UDP |
| 3 | Network | Маршрутизация между сетями | IP, ICMP |
| 2 | Data Link | Передача в пределах одной сети | Ethernet, MAC |
| 1 | Physical | Провода, радиоволны | Кабели, Wi-Fi |

### TCP/IP (4 уровня)

| Уровень | Протоколы |
|:---|:---|
| Application | HTTP, SSH, DNS, FTP |
| Transport | TCP, UDP |
| Internet | IP, ICMP |
| Network Access | Ethernet, Wi-Fi |

### Инкапсуляция

Каждый уровень добавляет свой заголовок при отправке и снимает при получении.

## 2. IP-адресация и подсети

### IP-адрес (IPv4)

32-битное число: `192.168.1.10`

### Маска подсети и CIDR

| Маска | CIDR | Хостов | Пример сети |
|:---|:---|:---|:---|
| 255.255.255.0 | /24 | 254 | 192.168.1.0/24 |
| 255.255.0.0 | /16 | 65 534 | 10.0.0.0/16 |
| 255.0.0.0 | /8 | 16 777 214 | 10.0.0.0/8 |

### Ключевые адреса в подсети

| Адрес | Назначение |
|:---|:---|
| 192.168.1.0 | Адрес сети |
| 192.168.1.1 | Обычно gateway |
| 192.168.1.255 | Broadcast |

### Частные диапазоны (RFC 1918)

| Диапазон | CIDR |
|:---|:---|
| 10.0.0.0 – 10.255.255.255 | /8 |
| 172.16.0.0 – 172.31.255.255 | /12 |
| 192.168.0.0 – 192.168.255.255 | /16 |

## 3. TCP vs UDP

| | TCP | UDP |
|:---|:---|:---|
| Надёжность | Гарантирует доставку | Не гарантирует |
| Соединение | Нужен handshake | Нет соединения |
| Скорость | Медленнее | Быстрее |
| Заголовок | 20 байт | 8 байт |
| Аналогия | Телефон | Радио |
