# Урок 04 — Сетевой стек Linux

## 1. Модели OSI и TCP/IP

### OSI (7 уровней)

| Уровень | Название | Задача | Примеры |
|:---|:---|:---|:---|
| 7 | Application | Приложение хочет отправить/получить данные | HTTP, SSH, DNS |
| 6 | Presentation | Формат данных, шифрование | TLS, JSON |
| 5 | Session | Управление сессиями | TCP-сессии, cookies |
| 4 | Transport | Доставка данных между процессами | TCP, UDP |
| 3 | Network | Маршрутизация между сетями | IP, ICMP |
| 2 | Data Link | Передача в пределах одной сети | Ethernet, MAC |
| 1 | Physical | Провода, радиоволны | Кабели, Wi-Fi |

### TCP/IP (4 уровня)

| Уровень | Протоколы |
|:---|:---|
| Application | HTTP, SSH, DNS, FTP |
| Transport | TCP, UDP |
| Internet | IP, ICMP |
| Network Access | Ethernet, Wi-Fi |

### Инкапсуляция

Каждый уровень добавляет свой заголовок при отправке и снимает при получении.

## 2. IP-адресация и подсети

### IP-адрес (IPv4)

32-битное число: `192.168.1.10`

### Маска подсети и CIDR

| Маска | CIDR | Хостов | Пример сети |
|:---|:---|:---|:---|
| 255.255.255.0 | /24 | 254 | 192.168.1.0/24 |
| 255.255.0.0 | /16 | 65 534 | 10.0.0.0/16 |
| 255.0.0.0 | /8 | 16 777 214 | 10.0.0.0/8 |

### Ключевые адреса в подсети

| Адрес | Назначение |
|:---|:---|
| 192.168.1.0 | Адрес сети |
| 192.168.1.1 | Обычно gateway |
| 192.168.1.255 | Broadcast |

### Частные диапазоны (RFC 1918)

| Диапазон | CIDR |
|:---|:---|
| 10.0.0.0 – 10.255.255.255 | /8 |
| 172.16.0.0 – 172.31.255.255 | /12 |
| 192.168.0.0 – 192.168.255.255 | /16 |

## 3. TCP vs UDP

| | TCP | UDP |
|:---|:---|:---|
| Надёжность | Гарантирует доставку | Не гарантирует |
| Соединение | Нужен handshake | Нет соединения |
| Скорость | Медленнее | Быстрее |
| Заголовок | 20 байт | 8 байт |
| Аналогия | Телефон | Радио |

### 3-way handshake

Клиент → Сервер: SYN
Клиент ← Сервер: SYN-ACK
Клиент → Сервер: ACK

### Состояния TCP

| Состояние | Значение |
|:---|:---|
| LISTEN | Ждёт входящих соединений |
| ESTABLISHED | Соединение активно |
| TIME_WAIT | Закрыто, но порт занят |
| CLOSE_WAIT | Один закрыл, второй ждёт |

## 4. Порты

| Диапазон | Название | Примеры |
|:---|:---|:---|
| 0–1023 | Well-known | 22 (SSH), 53 (DNS), 80 (HTTP), 443 (HTTPS) |
| 1024–49151 | Registered | 3306 (MySQL), 5432 (PostgreSQL), 6379 (Redis) |
| 49152–65535 | Dynamic/Ephemeral | Клиентские порты |

**Socket** = IP + порт. Например: `192.168.1.10:5432`

## 5. DNS (Domain Name System)

Преобразует имя → IP.

### Типы записей

| Тип | Что делает |
|:---|:---|
| A | IPv4-адрес |
| AAAA | IPv6-адрес |
| CNAME | Псевдоним |
| MX | Почтовый сервер |
| TXT | Текстовые данные |
| NS | DNS-серверы |

### TTL

Время кеширования записи в секундах.

---

## 6. DHCP

Автоматическая выдача IP-адресов.

**Процесс DORA:**
1. Discover — клиент ищет сервер
2. Offer — сервер предлагает IP
3. Request — клиент подтверждает
4. Acknowledge — сервер фиксирует

## 7. Linux сетевые команды

| Команда | Что делает |
|:---|:---|
| `ip addr` | IP-адреса интерфейсов |
| `ip route` | Таблица маршрутизации |
| `ss -tunap` | Сокеты и соединения |
| `ping` | Проверка доступности |
| `traceroute` | Маршрут до хоста |
| `curl` | HTTP-запросы |
| `dig` | DNS-запросы |
| `tcpdump` | Захват трафика |
| `iptables -L` | Правила firewall |
