# Урок 01 — Linux FHS

## 1. FHS (Filesystem Hierarchy Standard)

| Директория | Назначение |
|---|---|
| `/bin` | Essential binaries (bash, ls, cat) — доступны всем |
| `/sbin` | System binaries (reboot, fdisk) — только root |
| `/usr/bin` | Основные пользовательские программы |
| `/usr/sbin` | Основные системные программы |
| `/etc` | Конфигурационные файлы |
| `/var` | Переменные данные (логи, кэш, базы) |
| `/home` | Домашние директории пользователей |
| `/tmp` | Временные файлы (очищаются при reboot) |
| `/opt` | Стороннее ПО вне пакетного менеджера |
| `/proc` | Виртуальная ФС — runtime-информация ядра |
| `/sys` | Информация об устройствах и ядре (sysfs) |
| `/dev` | Устройства |

### Почему такая структура?
- Разделение статики (`/usr` может быть read-only) и динамики (`/var` — read-write)
- Предсказуемость: приложение всегда знает, где искать конфиг и логи

## 2. Навигация в shell

| Команда | Описание | Ключи |
|---|---|---|
| `pwd` | Текущий путь | — |
| `cd` | Сменить директорию | `~` (домой), `-` (назад), `..` (вверх) |
| `ls` | Список файлов | `-l` (детально), `-a` (включая скрытые), `-h` (human-readable) |
| `cat` | Вывести содержимое | Не для больших файлов! |
| `less` | Постраничный просмотр | `q` — выход, `/` — поиск |
| `touch` | Создать пустой файл / обновить время | — |
| `mkdir` | Создать директорию | `-p` (создать вложенность) |
| `rm` | Удалить | `-i` (спросить), `-r` (рекурсивно), `-f` (force) |
| `cp` | Копировать | `-r` (директории), `-p` (сохранить права) |
| `mv` | Переместить / переименовать | — |

## 3. Hard links, Soft links и inode

**inode** — структура данных ФС, содержащая метаданные файла (права, размер, указатели на блоки). Имя файла — это hard link на inode.

| | Hard link | Soft link (symlink) |
|---|---|---|
| Указывает на | inode | Имя файла (путь) |
| Работает при удалении оригинала | Да | Нет (broken link) |
| На директорию | Нет | Да |
| Пересекает ФС | Нет | Да |
| Команда | `ln file link` | `ln -s file link` |

**Проверка:** `ls -li` показывает inode-номер. Одинаковый inode у hard links.
