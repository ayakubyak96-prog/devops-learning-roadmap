# Урок 02 — Права доступа: chmod, chown, umask

## 1. Модель прав в Linux

Каждый файл имеет три класса доступа:

| Класс | Буква | Кто это |
|---|---|---|
| **u**ser | `u` | Владелец файла |
| **g**roup | `g` | Группа файла |
| **o**thers | `o` | Все остальные пользователи |

И три действия:

| Право | Буква | Число | На файле | На директории |
|---|---|---|---|---|
| **r**ead | `r` | 4 | Читать содержимое | Видеть список (`ls`) |
| **w**rite | `w` | 2 | Изменять содержимое | Создавать/удалять файлы внутри |
| e**x**ecute | `x` | 1 | Запускать программу | Заходить внутрь (`cd`) |

## 2. Числовая нотация

| Число | Бинарно | Символы | Значение |
|---|---|---|---|
| 7 | 111 | `rwx` | полный доступ |
| 6 | 110 | `rw-` | чтение + запись |
| 5 | 101 | `r-x` | чтение + исполнение |
| 4 | 100 | `r--` | только чтение |
| 0 | 000 | `---` | нет доступа |

Примеры:
- `chmod 700 file` — только owner
- `chmod 755 script.sh` — стандарт для исполняемых скриптов
- `chmod 644 file` — стандарт для обычных файлов
- `chmod 600 secret.ini` — только owner (пароли, ключи)

## 3. Символьная нотация

- `chmod u+x file` — добавить owner исполнение
- `chmod g-w file` — убрать у group запись
- `chmod o=r file` — установить others только чтение
- `chmod a+x file` — добавить всем исполнение

## 4. chown — смена владельца

```bash
chown user:group file         # сменить owner и группу
chown -R user:group dir       # рекурсивно
sudo chown root:root file     # от имени root
